So rechnet das Notenbuch

1. Mitarbeit (Sonstige Leistungen im Unterricht). Jede Spalte ist eine Stunde oder eine andere Leistung (Protokoll, Referat, Heft …). In Stunden gilt: Wer keinen Eintrag hat, bekommt die neutrale Note (Standard 3,5). Bei anderen Leistungsarten zählt nur, wer einen Eintrag hat. Stempel: ++ = 1,0, + = 2,0, ○ = neutral, – = 5,0, –– = 6,0 (einstellbar), F = fehlt, zählt nicht. Jede Leistungsart hat ein Gewicht; gestempelte Stunden können zusätzlich stärker zählen. Die Mitarbeitsnote ist der gewichtete Durchschnitt. Ausgefallene Stunden werden ignoriert.

2. Tests (schriftliche Übungen). Punkte werden in Prozent umgerechnet und über den Notenschlüssel in eine Note übersetzt. Feinschlüssel = 15‑Punkte‑Tabelle mit Tendenzen (2– = 2,3, 1+ = 0,7; die Gesamtnote wird nie besser als 1,0), Grobschlüssel = ganze Noten. Für eine einzelne Arbeit kann der Schlüssel um einige Prozentpunkte verschoben werden (Fairness‑Check). Tests zählen mit einstellbarem Anteil (Standard 25 %) zu den Sonstigen Leistungen. Leeres Feld = nicht mitgeschrieben, wird ignoriert. Anhang „n“ = nachgeschrieben, „z“ = Zeitverlängerung, nur als Vermerk.

3. Klassenarbeiten (nur in Fächern mit Klassenarbeiten, z. B. WP Naturwissenschaften). Gleiche Umrechnung, eigener Beurteilungsbereich. Nach APO‑SI werden beide Bereiche angemessen berücksichtigt, üblich ist 50 : 50 nach Beschluss der Fachkonferenz. Einstellbar.

4. Gesamtnote, Jahresnote, Zeugnisvorschlag. Gesamt = (100 % − KA‑Anteil) · Sonstige Leistungen + KA‑Anteil · Klassenarbeiten. Im zweiten Halbjahr kann die Note des ersten Halbjahres mit einstellbarem Anteil zur Jahresnote beitragen. Der Vorschlag rundet auf eine ganze Note. Bei x,40 bis x,60 wird ein Ermessensbereich angezeigt: Die Entscheidung triffst du und trägst sie als Zeugnisnote ein. Manuelle Noten haben Vorrang; Abweichungen ohne Bemerkung werden markiert.
